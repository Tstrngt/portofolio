# Portret

Voeg je foto hier toe als `tim-van-gorkom.webp` en commit het bestand.
De site toont het portret na de volgende build automatisch. Zonder foto verschijnt een monogram.

Voor lokaal uitproberen: open de website met `?preview=1`, klik op **Over Tim** en kies **Foto toevoegen**.
Deze selectie blijft alleen in die voorvertoning. Upload het echte bestand naar deze map om het blijvend te publiceren.
